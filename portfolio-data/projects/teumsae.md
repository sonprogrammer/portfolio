# 틈새(Teumsae)

## 프로젝트 개요

- 기간: 2026.10.27 ~ 현재
- 유형: 개인 프로젝트, AI 활용 개발 사례
- 상태: 실제 배포 후 지속 개발 중
- 서비스: https://teumsae-blush.vercel.app/
- GitHub: https://github.com/sonprogrammer/teumsae
- 설명: 등록된 일정과 개인별 가능 시간을 바탕으로 빈 시간을 찾고, 자연어 대화로 일정을 관리하는 개인 AI 스케줄러입니다.

## 서비스 소개와 개발 상태

틈새는 등록된 일정과 개인별 가능 시간을 바탕으로 빈 시간을 찾고, 자연어 대화로 일정을 관리하는 개인 AI 스케줄러입니다. AI가 변경안을 제안하면 사용자가 확인하고, 서버 검증을 통과한 뒤 일정에 반영합니다.

개인 프로젝트로 실제 배포해 사용 중이며, 사용자 경험과 기능을 계속 개선하고 있습니다.

## 핵심 구현: 달력과 일정 가능 시간 설정

주간·월간 달력에서 일정을 확인하고, 요일별 가능 시간과 날짜별 불가일을 관리합니다. 다른 기기에서 변경한 일정은 화면 복귀 시 확인하거나 새로고침할 수 있습니다.

- PWA 홈 화면 설치 지원
- 일정 푸시 알림 지원

## 핵심 구현: AI 대화와 일정 변경 확인

자연어로 일정 조회와 빈 시간 검색을 요청할 수 있습니다. 일정 등록·수정·삭제는 AI 제안만으로 실행하지 않고, 사용자가 내용을 확인한 뒤 진행합니다.

- Groq API로 GPT-OSS 모델 호출
- Tool Calling으로 일정 조회·빈 시간 검색·등록·수정·삭제 기능 연결
- 사용자가 일정 변경 내용을 확인한 뒤 서버 검증을 거쳐 실행

## 일정 변경 실행 구조

**AI 변경 제안 → 사용자 확인 → 서버 검증 → 일정 반영**

1. AI가 변경할 일정과 내용을 제안합니다.
2. 사용자가 확인 카드에서 제안을 승인합니다.
3. 서버가 로그인 사용자와 일정 소유자를 확인하고, 기존 일정의 버전과 변경 충돌 여부를 검증합니다.
4. 검증을 통과한 경우에만 데이터베이스에 반영하고 달력과 일정 목록을 갱신합니다.

AI는 실제 저장 여부나 권한을 결정하지 않습니다. 사용자 확인과 서버 검증을 거쳐야 일정이 변경됩니다.

## 직접 수행한 역할

- 초기 요구사항과 사용 중 발견한 개선사항을 GitHub Issue로 관리하고, 완료 조건을 정해 기능별 작업 범위를 구체화했습니다.
- Codex와 서브에이전트를 구현·리뷰에 활용하고, 변경 코드를 검토해 필요한 부분을 직접 수정했습니다.
- 기능별 브랜치와 Git worktree에서 작업하고 PR 단위로 변경사항을 검증·통합했습니다.
- 데스크톱과 모바일에서 주요 사용자 흐름을 직접 확인했습니다.
- 프론트엔드, 백엔드, QA, 보안 검토 스킬을 작업 유형에 맞게 적용하고, 반복적으로 발생한 문제와 검증 항목을 반영해 스킬을 지속적으로 개선했습니다.
- GitHub Actions로 타입 검사, 린트, 테스트, 빌드 CI를 구성하고 Husky와 lint-staged로 커밋 전 검사를 자동화했습니다.
