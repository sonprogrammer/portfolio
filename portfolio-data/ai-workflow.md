# 손영진의 AI 활용 방식

## 기본 관점

AI에게 개발을 맡기기보다 직접 정한 방향과 설계를 기준으로 개발 과정의 생산성을 높이는 도구로 활용합니다.

어떤 서비스를 만들지와 화면이 어떤 방향이어야 하는지는 먼저 직접 결정합니다. 이후 프로젝트를 구체화하거나 빠르게 MVP 화면을 만들고 코드 분석과 반복 작업의 시간을 줄이는 데 AI를 활용합니다.

## AI를 활용하는 작업

- 프로젝트 아이디어와 요구사항 구체화
- 대략적인 UI 방향을 정한 뒤 빠른 MVP 화면 구체화
- 코드 분석 및 반복 구현 작업 보조
- 문제가 발생했을 때 원인과 해결 방향 논의
- 필요한 경우 새로운 구현 방법과 선택지 탐색

## 역할 기반 에이전트 워크플로 실험

AI를 사용하는 방법 자체도 하나의 개발 역량으로 학습하고 있습니다. Codex 기반 사이드 프로젝트에서 기획, 백엔드, 프론트엔드, QA 역할별 작업 범위와 완료 조건을 정의하고 생성 결과를 검증한 뒤 통합하는 방식을 적용했습니다.

### Role & Scope

GitHub Issue에 기획, 백엔드, 프론트엔드, QA 역할별 요구사항과 작업 범위, 완료 조건을 정의했습니다. 운영 환경 변경 제한과 작업 간 의존성도 함께 명시해 각 에이전트가 맡은 범위 안에서 작업하도록 구성했습니다.

### Workspace & Context

tmux 세션과 Git Worktree로 작업 환경을 분리하고, Skill과 프로젝트 문서를 통해 역할별 지침과 필요한 참고 정보를 제공했습니다.

### Verification & Integration

생성 코드를 요구사항과 API 계약에 맞춰 검토하고, 최종 커밋의 GitHub Actions CI 검사와 QA 결과를 확인한 뒤 PR 단위로 통합했습니다.

## AI 시대의 개발자에 대한 관점

AI를 개발자의 대체재가 아니라 개발 역량을 확장하는 도구로 정의합니다.

여러 기업이 AI를 실제 개발 프로세스와 생산성 향상에 활용하는 사례를 접하면서, 앞으로는 AI를 단순히 사용할 줄 아는 것보다 개발 과정에 어떻게 적용하고 통제할 수 있는지가 중요해질 것이라고 생각했습니다.

AI 도입으로 개발자의 역량이 약화될 것을 우려하기보다 새로운 도구를 빠르게 흡수하고 근본적인 아키텍처 설계 및 구현 역량과 결합해 더 완성도 높은 가치를 만드는 개발자로 성장하는 것이 목표입니다.

AI로 개발 속도와 구현 역량을 확장하되, 사용자가 서비스를 이용하며 느끼는 감정과 맥락을 이해하고 이를 사용자 경험에 녹여낼 수 있는 개발자가 되고자 합니다.
