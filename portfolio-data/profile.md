# 손영진 프로필과 교육

## 기본 소개

손영진은 프론트엔드 개발을 중심으로 프로젝트를 직접 설계하고 구현하며 새로운 기술과 개발 방식을 꾸준히 학습하고 있습니다.

현재 Architecture, Data Flow, Performance, AI-assisted Development를 중심으로 Web Engineering과 AI 역량을 강화하고 있습니다.

## 학력

- 학교: 한서대학교
- 전공: 항공소프트웨어공학과
- 졸업: 2024년 2월

## 엘리스 웹 개발자 트랙 6기

- 기간: 2023.08 ~ 2023.12
- 상태: 수료

프론트엔드부터 서버와 데이터베이스까지 웹 서비스의 전체 흐름을 학습했고, 팀 프로젝트를 통해 실제 API 연동과 협업 과정을 경험했습니다.

### Frontend

React와 TypeScript를 중심으로 컴포넌트 기반 UI 구현과 상태 관리 등 프론트엔드 웹 개발의 기본 구조를 학습했습니다.

### Web and Backend Fundamentals

Node.js와 Express를 사용하며 HTTP 요청과 응답, REST API, CRUD, 서버 애플리케이션의 기본 흐름을 학습했습니다.

### Database and Authentication

MongoDB를 활용한 데이터 저장과 조회를 학습하고 세션과 JWT 토큰 등 웹 인증 방식의 기본 개념을 익혔습니다.

### Team Development

Git 기반 협업, 데일리 스크럼, 백엔드 팀원과의 API 연동을 경험하며 실무형 팀 개발 프로세스를 익혔습니다. Issue 발행, 브랜치 전략, Pull Request 기반 코드 리뷰를 팀 프로젝트에 적용했습니다.

### 교육 과정 기술

React, TypeScript, Node.js, Express, MongoDB, HTTP, REST API, CRUD, Session, JWT, Git
